## ⚠️ Gotchas & Pitfalls

### 1. Git Permissions
**Problem:** VM cannot push to GitHub (permission denied)  
**Workaround:** Always push from local Mac, pull on VM  
**Reason:** SSH key not configured with org write access

### 2. Feature Flags
**Problem:** V2 enabled by default  
**Risk:** If V2 has bugs, affects all users  
**Mitigation:** Can quickly disable in `lib/features.ts`

```typescript
// To disable V2:
const defaultFlags = {
  useNewFileUpload: false,
  useNewCSVParser: false,
  useNewBatchProcessor: false,
}
```

### 3. V1 vs V2 Coexistence
**Problem:** Both V1 and V2 code exist  
**Why:** Safe fallback during migration  
**TODO:** Remove V1 after V2 proven stable (2-4 weeks)

### 4. Test Timeout
**Problem:** Tests might timeout on slow connections  
**Fix:** Increase timeout in vitest.config.ts

```typescript
export default defineConfig({
  test: {
    testTimeout: 10000, // Increase from default 5000
  },
})
```

### 5. EventSource in Development
**Problem:** EventSource connections stay open  
**Impact:** Can cause "too many connections" error  
**Fix:** Always cleanup, restart dev server if stuck
